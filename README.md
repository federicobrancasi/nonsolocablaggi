# NonSoloCablaggi - published website

**Preview: <https://branca.si/nonsolocablaggi/>**

This repository contains only the generated public website in `site/` and the
workflow that deploys it with GitHub Pages. The development source and its
history are kept in a separate private repository.

Website updates are built in the private repository and pushed here
automatically. Do not edit `site/` by hand: the next build replaces it.

Every update to `site/` deploys the website. To redeploy the current files,
use **Actions > Deploy website > Run workflow**.

The preview is marked `noindex, nofollow`. Its HTML, CSS, JavaScript, images
and PDFs are public, as with any publicly accessible website.
